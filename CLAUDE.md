# Agent instructions

Read `PLAN.md` before doing anything. It is the single source of truth for requirements, data rules, design, decisions, and status.

Keep `PLAN.md` current. In the same session as any change, update the affected sections and the Status section (done, open questions, next steps). Replace stale text instead of appending to it, and keep the file concise. A new agent must be able to pick up from `PLAN.md` alone.
